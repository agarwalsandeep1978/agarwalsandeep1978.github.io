VARISH AGARWAL WEBSITE — UPDATED PACKAGE
========================================

This package contains the revised static website. No photos are used on the website.

PUBLISHING THE UPDATE USING GITHUB DESKTOP
1. Download and extract this ZIP on your computer.
2. Open GitHub Desktop and select the repository:
   agarwalsandeep1978/agarwalsandeep1978.github.io
3. In GitHub Desktop, choose Repository > Show in Explorer.
4. IMPORTANT: back up the current repository folder first (copy it somewhere outside the repo).
5. Copy the CONTENTS of the extracted `varish_website` folder into the repository folder.
   - Copy index.html and all other .html files to the repository root.
   - Copy the `assets`, `certificates`, and `reports` folders too.
   - Do not copy the outer folder `varish_website` as a nested folder.
   - If asked to merge folders, choose merge/replace. New files should be added.
6. Return to GitHub Desktop. Review the changed files.
7. Enter a summary such as: `Update portfolio content and project pages`.
8. Click Commit to main, then Push origin.
9. Wait 2–5 minutes, then open https://varishagarwal.com in a private/incognito window and test the homepage, CV, Blogs, Beach Mitra, hoodie, glove and autonomous-car pages.
10. Keep GitHub Pages and DNS settings unchanged; the custom domain and HTTPS are already configured.

NOTES
- `blogs.html` contains the two blog stories provided.
- `autonomous-car.html` links to the two Grade 10 design report PDFs.
- `reports/` contains project reports and supporting PDFs.
- The Haryanvi cookbook PDF is large (~93 MB). GitHub's single-file limit is 100 MB; it is below that limit but may take time to push.
- If GitHub Desktop warns that a file exceeds 100 MB, stop and tell us before trying to push.
